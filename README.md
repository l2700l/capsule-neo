# Capsule Neo Proxy

HTTP-прокси и сервер реализации протокола для исследования и замены оригинального сервера VK Capsule Neo.

Проект предназначен для перехвата, анализа и обработки запросов устройства, реализации собственных обработчиков и воспроизведения поведения оригинального сервера.

Основная цель — обеспечить автономную работу VK Capsule Neo без зависимости от оригинальной серверной инфраструктуры VK.

## Зависимости

Для работы проекта необходимы:

- **Python 3.11+**
- **Docker Compose** — для запуска Nginx.

SSL-сертификаты находятся в каталоге `certs/` внутри проекта.

## Запуск

### 1. Запустить Python-сервер

Создание виртуального окружения и установка зависимостей:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip3 install -r requirements.txt
```

При необходимости создайте файл конфигурации:

```bash
cp .env.example .env
```

Запуск:

```bash
python3 -m capsule_proxy
```

По умолчанию Python-сервер слушает `0.0.0.0:8082`.

### 2. Запустить Nginx

Nginx используется для HTTPS, устройство работает через запрос по домену.

Сам Python-сервер запускается непосредственно на хосте. Nginx запускается либо в Docker, либо на хосте (добавляется вручную).

Сертификаты уже находятся в проекте, поэтому дополнительная настройка SSL не требуется.

Запуск:

```bash
docker compose up -d
```

Остановка:

```bash
docker compose down
```

Для доступа контейнера Nginx к Python-серверу на хосте используется `host.docker.internal`.

На Linux для этого может потребоваться настройка в `docker-compose.yml`:

```yaml
extra_hosts:
  - "host.docker.internal:host-gateway"
```

Основной HTTP-сервер использует порт `8082`, WebSocket-сервис — `8083`.

### 3. Перенаправить DNS-записи устройства

Чтобы колонка обращалась к локальному серверу вместо оригинального, необходимо настроить DNS-переопределение на роутере.

Создайте локальную DNS-запись:

| Домен | Адрес |
|---|---|
| `vc.go.mail.ru` | Локальный IP компьютера с Nginx |

Например, если компьютер с сервером имеет адрес `192.168.1.100`, укажите его в качестве адреса для домена `vc.go.mail.ru`.

После этого устройство должно получать локальный IP вместо оригинального адреса сервера, а HTTPS-соединение на порту `443` будет принимать Nginx.

Названия и расположение настроек DNS зависят от прошивки роутера. Ищите функции вроде *Local DNS*, *DNS Host Mapping*, *Static DNS* или *DNS Rebinding*.

Если роутер не позволяет создавать записи для отдельных доменов, можно использовать локальный DNS-сервер, например AdGuard Home или dnsmasq.

**Важно:**

- Компьютер с сервером должен иметь постоянный локальный IP или DHCP-резервацию.
- DNS-переопределение действует только на устройства, использующие настроенный DNS-сервер.

## Интеграция с Capsule Marusya

Обработка голосовых запросов вынесена в отдельный проект — [Capsule Marusya](https://github.com/l2700l/capsule-marusya).

Он отвечает за распознавание речи, классификацию запросов, выполнение навыков и синтез голосовых ответов.

Следующие группы эндпоинтов передаются в Capsule Marusya:

- `/phrase/create`
- `/phrase/create/{chunk_name}`
- `/phrase/add`
- `/phrase/result`
- `/stream`

Таким образом, Capsule Neo Proxy отвечает за взаимодействие с устройством и реализацию протокола, а Capsule Marusya — за интеллектуальную обработку голосовых запросов.

## Маскирование заголовков

По умолчанию чувствительные HTTP-заголовки маскируются в логах и генерируемых командах `curl`.

Для отключения маскирования при локальной отладке:

```bash
CAPSULE_REDACT_SENSITIVE_HEADERS=0 python -m capsule_proxy
```

Настройка влияет только на логирование и вывод команд `curl`, но не на заголовки, отправляемые серверу.

Не публикуйте логи и сохранённые запросы без предварительной проверки: они могут содержать токены, cookies, идентификаторы устройства и другие конфиденциальные данные.

## Добавление HTTP-маршрутов

Для добавления нового обработчика:

1. Добавьте функцию-обработчик в соответствующий модуль каталога `capsule_proxy/handlers/`.
2. Зарегистрируйте маршрут в `capsule_proxy/routes.py`.
3. Укажите HTTP-метод, регулярное выражение пути, ожидаемый тип содержимого и функцию-обработчик.

Обработчик возвращает JSON-совместимый объект либо кортеж:

```python
(status, response_object, response_type)
```

Поддерживаемые типы ответа: `json` и `msgpack`.

## План дальнейшей работы

### 1. Исследование протокола

- Изучить назначение и форматы всех обнаруженных типов команд из прошивки.
- Разобраться с работой плейлистов и командами управления воспроизведением. Для полноценного исследования потребуется подписка на VK Музыку.
- Исследовать последовательности событий и взаимодействие колонки с сервером в различных сценариях.

### 2. Доработка базовых функций

- Довести до конца реализацию базовых навыков и сценариев взаимодействия.
- Доработать обработку отказа и отмены действий.
- Проверить работу таймеров, напоминаний и будильников: определить, кто отвечает за отсчёт времени и момент срабатывания — сервер или сама колонка.
- Проверить корректность обработки уведомлений и их отмены.

### 3. Проверка совместимости

- Проверить реализованные сценарии на реальном устройстве.
- Выявить недостающие команды и последовательности обмена.
- Исправлять ошибки и постепенно расширять покрытие протокола.

## Совместимость и обратная связь

**Capsule Neo Proxy уже способен полноценно заменять оригинальный сервер VK для реализованных сценариев использования.**

При этом проект продолжает развиваться, и в отдельных сценариях возможны ошибки, некорректное поведение или недостаточно изученные особенности протокола.

Если вы столкнулись с проблемой, пожалуйста, создайте [Issue в GitHub](https://github.com/l2700l/capsule-neo/issues), приложив описание ситуации и, по возможности, обезличенные логи запросов.

Проект развивается на основе исследования реального поведения устройства и обратной связи пользователей.
